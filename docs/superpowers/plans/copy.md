## How a WhatsApp message reaches the inbox

Webhooks from the Meta WhatsApp Cloud API are queued with BullMQ, processed by workers, saved to MongoDB and broadcast through Redis Streams and Socket.IO.

Webhook: Meta WhatsApp Cloud API. BullMQ queue: Queued, fault-tolerant ingestion. Worker: Processes each event. MongoDB: One database per tenant. Redis Streams: Tenant-scoped broadcast. Socket.IO: Real-time delivery. Inbox: Agents see only their assigned chats.
